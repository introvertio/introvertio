## Hey there! I’m Oyindamola [dami]. I design and build products across platforms, working on how they work, how they're used, and how they feel. I collaborate with thinkers and builders to turn ideas into reality.

Primarily using ![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white) and ![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?logo=typescript&logoColor=white) or ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black) programming languages, I build end-to-end products and systems. Combining ![React](https://img.shields.io/badge/React-61DAFB?logo=react&logoColor=black) with ![Next.js](https://img.shields.io/badge/Next.js-000000?logo=nextdotjs&logoColor=white), ![Tailwind CSS](https://img.shields.io/badge/Tailwind%20CSS-06B6D4?logo=tailwindcss&logoColor=white) and ![Motion](https://img.shields.io/badge/Motion-0055FF?logo=framer&logoColor=white), I create fast, responsive, scalable, and interactive web interfaces.

For mobile development, ![React Native](https://img.shields.io/badge/React%20Native-61DAFB?logo=react&logoColor=black) and ![Expo](https://img.shields.io/badge/Expo-000020?logo=expo&logoColor=white) help me deliver cross-platform applications with consistent performance and feel.

For desktop applications, I use ![Electron](https://img.shields.io/badge/Electron-47848F?logo=electron&logoColor=white) to build cross-platform experiences that share the same performance and interaction principles.

On the backend, I design scalable APIs with ![Django](https://img.shields.io/badge/Django-092E20?logo=django&logoColor=white), ![Django REST Framework](https://img.shields.io/badge/Django%20Rest%20Framework-A30000?logo=django&logoColor=white), and ![FastAPI](https://img.shields.io/badge/FastAPI-009688?logo=fastapi&logoColor=white). I use ![Supabase](https://img.shields.io/badge/Supabase-3FCF8E?logo=supabase&logoColor=white) with ![PostgreSQL](https://img.shields.io/badge/PostgreSQL-4169E1?logo=postgresql&logoColor=white) for larger, structured applications that require real-time data and more complex features, while ![MongoDB](https://img.shields.io/badge/MongoDB-47A248?logo=mongodb&logoColor=white) serves as a flexible, document-based option for smaller applications.

I deploy through ![Vercel](https://img.shields.io/badge/Vercel-000000?logo=vercel&logoColor=white) and ![Render](https://img.shields.io/badge/Render-46E3B7?logo=render&logoColor=white), and keep everything version-controlled with ![Git](https://img.shields.io/badge/Git-F05032?logo=git&logoColor=white) and ![GitHub](https://img.shields.io/badge/GitHub-181717?logo=github&logoColor=white). **Creating systems that are reliable, maintainable, and ready for growth.**
